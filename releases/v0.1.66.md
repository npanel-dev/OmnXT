# OmnXT Node v0.1.66

本版本更新 Node 与 CLI，程序版本均为 `0.1.66`。源码为
[`948b54ad450a6a27f02add92dc6f36358661b3f3`](https://github.com/SunGreatSage/OmnXT/commit/948b54ad450a6a27f02add92dc6f36358661b3f3)，
包含本轮 SimNet 下载推进修复和基础 VLESS relay 修复。

## 修复内容

- 按 ClientOpen 中实际 offer 安装 Node 发送窗口，纠正 ServerAccept 的客户端窗口视角；
  不对称窗口、真实抖动 offer、新旧线上合同夹具及完整闲置会话恢复均有回归。
- 消费信用可靠归还，队列满保留已消费债务，小尾债使用持久 deadline；reset 后迟到 DATA
  不再因等待仅写 flush 卡住健康流。
- 待发数据按流轮转，target 读取前联合预留真实发送信用与物理预算；零信用仍能识别 EOF，
  未读 payload 保持先 DATA 后 FIN。空闲 target 不提前占用读取信用；会话仍有信用时，
  可绕过零信用流的待发队列。共享会话信用被耗尽时仍会对其他流形成背压。
- 载体由一个 owner 独立推进读写，采用有界就绪批处理和控制优先，保持部分帧与同流顺序；
  在复制、编码和 HMAC 前检查队列容量，减少拥塞时的重复工作。
- 基础 VLESS 两方向独立推进，部分写更新活动计数，保持响应头、FIN、取消与超时策略。
  默认逻辑窗口、H2 参数和 TCP 缓冲未调整，Vision/Encryption legacy relay 正文保持原实现。

## 构建与产物

按上一个正式版 v0.1.65 的 Linux 产物合同，本地构建两个 GNU Linux 架构，发布四个附件：

```text
omnxt-node-x86_64-unknown-linux-gnu.tar.gz
omnxt-node-x86_64-unknown-linux-gnu.tar.gz.sha256
omnxt-node-aarch64-unknown-linux-gnu.tar.gz
omnxt-node-aarch64-unknown-linux-gnu.tar.gz.sha256
```

使用 Rust 1.94.1、cargo-zigbuild 0.22.3、Zig 0.14.0，目标指定 `.2.28`，默认 features 与
仓库 Release 配置。构建命令保持 `--release --locked`，显式注入 Node 源码 revision。
未使用 GitHub Actions 构建。包内保留顶层目录及 `bin/omnxt-node`、`bin/omncli`、
`DEPLOY.md` 和 `manifest.json`；归档不包含 macOS `._*` 文件。

二进制与归档校验值、实际动态 GLIBC 需求及打包生成时间记录在 [发布清单](https://github.com/npanel-dev/OmnXT/blob/main/releases/v0.1.66.json)。
Node 诊断输出带源码 revision；CLI 的源码身份由构建清单与二进制 SHA256 固定。

## 验证结果与限制

传输修复完成了 407 项相关测试，12 项既有忽略；格式、diff check 与 Linux workspace check 通过。
版本同步后重新执行了 workspace check，发布产物另核对 ELF 架构、动态 GLIBC 需求、程序版本、
CLI 配置校验及 Node 启动诊断。具体产物验证状态见发布清单。

严格匹配依赖和编译参数的本地 H2 Release 对照，三轮吞吐中位数约 +0.13%，没有观察到稳定回退；
并发小响应由 336–529 ms 降至 5–18 ms，响应预算峰值约 69.3 MB 降至 2.13 MB。
Debug 吞吐中位数仍下降约 5.56%，默认窗口持续慢读的协议 Pong 仍等待约 14 秒。
该测试使用真实 H2 和 loopback TCP，慢读由载体应用包装器模拟；未包含 WAN、TLS、真实 SDK
连接池或客户设备，不能承诺现场提速。

## 升级说明

本轮服务端窗口、调度和载体修复需要更新 Node。客户端消费返窗修复还需要应用对应的新 SDK；
只升级 Node 不等于完整应用两端改动。旧合同互通由帧编解码与 runtime 夹具覆盖，不能替代旧版本
二进制和客户设备互通验收。本次发布没有重启或升级客户服务器。

安装指定版本：

```bash
curl -fsSL https://raw.githubusercontent.com/npanel-dev/OmnXT/main/install.sh | sudo bash -s -- 0.1.66
```

下载归档后可在同一目录手动校验：

```bash
sha256sum -c omnxt-node-x86_64-unknown-linux-gnu.tar.gz.sha256
```

ARM64 对应替换文件名为 `omnxt-node-aarch64-unknown-linux-gnu.tar.gz.sha256`。
现有安装脚本没有自动验证这个 checksum 文件，不把提供校验文件称为安装器已执行校验。
